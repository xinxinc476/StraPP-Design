# StraPP-Design

Code for the paper **"Bayesian design of clinical trials using the scale transformed power prior."**

## Paper

The paper has been published in the *Journal of Biopharmaceutical Statistics*:

[Link to the paper](https://doi.org/10.1080/10543406.2024.2330205)

## Repository contents

- `R/`: R scripts for data generation, posterior sampling, simulations, and summaries for the single hypothesis case.

- `Stan/`: Stan models used by the R scripts for the single hypothesis case.

- `multi_hypotheses/`: R and Stan code for the multiple-hypotheses case.

The `.Rmd` and generated `.html` files contain summaries and results from the simulation studies.
